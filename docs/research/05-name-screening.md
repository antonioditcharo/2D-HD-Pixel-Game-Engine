# Research 05: Product-Name Screening

> **What this document answers:** which of five candidate product names collide with
> existing trademarks or products, and which look safest to take forward.
>
> **This is a preliminary knockout screening, not legal clearance.** It finds obvious
> conflicts cheaply. It cannot find everything a professional search would: similar-sounding
> marks, unregistered rights, national registers outside the US and EU, or company names.
> Have a trademark professional clear the chosen name before any public launch.
>
> Screening date: **10 November 2026**. `[S#]` refers to [`../sources.md`](../sources.md).
> Sections labelled **Analysis** are the author's assessment.

---

## 1. Why a new name is needed

- "HD-2D" is a Square Enix trademark, so the product must not use it (`plan/09`, R-06).
- "Diorama" has been the working codename in these documents. It was never cleared.
- The owner asked for 3–5 candidates to be screened (`plan/09` §5, Q-08).

## 2. Candidates

| Name | Idea behind it |
|---|---|
| **Diorama** | The current codename: pixel-art scenes as miniature dioramas |
| **Pixelwright** | A "wright" is a maker, as in playwright or shipwright |
| **Tiltbox** | Tilt-shift blur plus a box you build worlds in |
| **Lanternwork** | Lantern light and handcraft: lit pixel scenes |
| **Glimmerbox** | A box of glowing scenes |

## 3. What was checked, and how

| Check | Method | Result quality |
|---|---|---|
| **US trademarks** | USPTO Trademark Search, wordmark search, run in a browser on the day [S94]. Each name was searched as one word and as two words. | Direct query of the official register |
| **EU trademarks** | EUIPO eSearch plus, basic search, run in a browser on the day [S95]. One-word and two-word forms. | Direct query of the official register |
| **International (WIPO)** | WIPO Global Brand Database [S96] | **Not queried.** The site puts an automated-access check in front of its search, and that check was not bypassed |
| **Games on Steam** | Steam store search for each name [S97] | Direct query |
| **Code projects** | GitHub repository-name search for each name [S98] | Direct query |
| **Products on the web** | General web search for each name, alone and with "software", "game" and "trademark" | Search-engine results only |
| **Domain names, app stores, company registers** | — | **Not checked** |

Two limits of the register searches:

- They look for the same or nearly the same words. They do not judge whether a
  different-looking mark is *confusingly similar*, which is the legal test.
- For the two-word forms, the USPTO search returns thousands of loose matches (any mark
  containing either word). Only the 100 highest-ranked results were examined for the exact
  phrase. Exact-phrase matches are ranked first, so a miss is unlikely but possible.

## 4. Findings per name

### 4.1 Diorama: high risk

| Where | What was found |
|---|---|
| **EU register** [S95] | **DIORAMA** is **registered** to Bratte Ltd. in classes 9 and 42 (no. 019258912). Classes 9 and 42 are the software classes. Two more registered marks, "Diorama" (no. 018164553) and "DIORAMA" (no. 018870923), cover classes 41 and 42. Christian Dior Couture holds DIORAMA in classes 9, 14 and 18. |
| **US register** [S94] | 24 results. A **live pending application** for **DIORAMA** by Bratte Ltd. (serial 99473001, filed 31 October 2025) covers online software "for use in editing video graphics" in class 42. Bratte's earlier class 9 application (serial 98239455) is dead. Also live: DIORAMA LEAGUE (class 42 software, pending), DIORAMA PEDALS (class 9, guitar effects), and Christian Dior Couture's DIORAMA registration (its class 9 part is cancelled). |
| **Steam** [S97] | 308 results for "diorama", including *Diorama Builder*, *Diorama Maker*, *Diorama Worlds* and *Kriegsfront Battlescaper - Diorama Editor*. |
| **GitHub** [S98] | 1,023 repositories with "diorama" in the name. |

**Analysis:** the same word is already registered for software in the EU and is being
applied for in the US for graphics software. It is also an ordinary descriptive word in
games, which makes it both crowded and hard to protect. It should not become the product
name.

### 4.2 Pixelwright: high practical risk

| Where | What was found |
|---|---|
| **US register** [S94] | No result for "pixelwright". No exact-phrase result for "pixel wright". |
| **EU register** [S95] | No result for either form. |
| **Products** [S99] | **Pixelwright** (pixelwright.app) is an existing browser-based "pixel-art studio for game art", launched in 2026, with palettes, rigs, tiles, animation and exports to Aseprite, Godot and Unity. |
| **GitHub** [S98] | 8 repositories, several of them pixel-art tools: a pixel-art editor with layers, animation and bone rigging; a pixel-art guide; pixel art for AI agents. |
| **Steam** [S97] | No results. |

**Analysis:** nothing is registered, but a product with the same name already exists in
exactly our field: pixel art for games. Unregistered use can still create rights, and two
pixel-art tools with one name would confuse users regardless. Avoid.

### 4.3 Tiltbox: low risk found

| Where | What was found |
|---|---|
| **US register** [S94] | No result for "tiltbox". No exact-phrase result for "tilt box". |
| **EU register** [S95] | No result for either form. |
| **Products** [S100] | **TiltBox**, a do-it-yourself handheld game console with an 8×8 LED matrix and tilt controls, designed at a makerspace in Leuven and shared freely. Also "TiltBox" plastic storage boxes for small parts, sold by tool suppliers. |
| **GitHub** [S98] | 12 small repositories, including the TiltBox console project. The largest has 1 star. |
| **Steam** [S97] | No results. |

**Analysis:** no register conflict was found. The hobby console is game-related but is a
small hardware project, not software or a commercial product. The storage boxes are in an
unrelated field.

### 4.4 Lanternwork: low risk found

| Where | What was found |
|---|---|
| **US register** [S94] | No result for "lanternwork". No exact-phrase result for "lantern work" or "lantern works". |
| **EU register** [S95] | No result for either form. |
| **GitHub** [S98] | 5 repositories with no stars. One is "Lanternwork for Foundry VTT", an add-on for a tabletop role-playing tool. Others use "Lantern Works" or "Lanternworks". |
| **Products** | Web search found no product called Lanternwork. Many companies use "Lantern" alone, including a game studio called Lantern Studio [S101]. |
| **Steam** [S97] | No results. |

**Analysis:** no register conflict was found. "Lantern" is a common word in software and
game names, so marks built on LANTERN deserve a closer look in a professional search.

### 4.5 Glimmerbox: moderate risk

| Where | What was found |
|---|---|
| **US register** [S94] | No result for "glimmerbox". **THE GLIMMER BOX** is **registered** (reg. no. 8013876, serial 99216831) to an individual in France for jigsaw puzzles in class 28. |
| **EU register** [S95] | No result for either form. |
| **GitHub** [S98] | 1 repository, a mobile app with no stars. |
| **Products** | Web search found decorative "Glimmer" boxes for the home. Trademark directories list GLIMMER STUDIOS for video game software and GLIMMERJAM for app software [S102]. |
| **Steam** [S97] | No results. |

**Analysis:** class 28 is the class for games and toys, which is next door to video games.
A registered mark that differs only by "The" and a space is a real, if not certain,
obstacle.

## 5. Summary and recommendation

| Rank | Name | Risk found | Main reason |
|---|---|---|---|
| 1 | **Tiltbox** | Low | Nothing on either register; only a hobby hardware project and storage boxes |
| 1 | **Lanternwork** | Low | Nothing on either register; "Lantern" itself is a crowded word |
| 3 | **Glimmerbox** | Moderate | THE GLIMMER BOX is registered in the US in the games and toys class |
| 4 | **Pixelwright** | High | An existing pixel-art tool for game art already uses the name |
| 5 | **Diorama** | High | Registered for software in the EU, pending in the US, and a crowded descriptive word |

**Analysis: recommendation**

1. **Do not ship as "Diorama".** Keep it only as an internal codename until a name is
   chosen, then replace it everywhere.
2. **Take Tiltbox or Lanternwork forward,** or propose new candidates and screen them the
   same way. Choosing between the two is a matter of taste, not of risk: this screening
   found no difference between them.
3. **Before any public launch,** have a trademark professional clear the chosen name. That
   search should cover similar-sounding marks, WIPO and national registers, and
   unregistered use.
4. **After choosing:** rename the GitHub repository (its current name is close to
   "HD-2D"), and check that a matching domain name is available. Neither was checked here.

The choice is tracked as open question Q-09 in `plan/09` §6.
