# 2D-HD-Pixel-Game-Engine

HD Pixel game engine with all the needed pipelines and systems built in, including sprite editing, animating, and all other workflows to make a pixel game.

**Goal:** a Windows-native, all-in-one, **no-code** engine for making HD-2D-style pixel
games, from first sketch to a shipped game on Steam, without writing code.

## Status

**Planning.** No engine code exists yet. The research and the full engine plan are in
[`docs/`](docs/README.md):

- **Research:** the HD-2D visual style; existing engines and no-code tools; content tools
  and workflows; no-code paradigms.
- **Plan:** vision, feature catalogue, architecture, rendering pipeline, no-code logic
  system, editor UX, technology decisions (ADRs), roadmap, risks and open questions.

Start with the [executive summary](docs/README.md#executive-summary).
